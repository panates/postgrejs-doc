# DataMappingOptions

| Key           | Type     | Default | Description                                                                          |
|---------------|----------|---------|-----------------------------------------------------------------------------------------|
| utcDates      | `boolean`| `false` | If true, UTC time is used for date decoding, else the system time offset is used       |
| fetchAsString | `OID[]`  |         | Data type OIDs that should be fetched as plain strings instead of their mapped JS type |
